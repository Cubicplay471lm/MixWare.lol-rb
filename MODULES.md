# MixWare.lol V3.0.0 — module map

main.lua is the only entry point.

- modules/core/Core.lua — API, settings, themes, utilities, notifications, shared state.
- modules/combat/Aimbot.lua — aimbot and target logic.
- modules/combat/HeadMover.lua — Head Mover.
- modules/combat/TriggerBot.lua — TriggerBot.
- modules/combat/HitboxExpander.lua — Hitbox Expander.
- modules/visuals/ESP.lua — player ESP.
- modules/visuals/Crosshair.lua — crosshair.
- modules/visuals/ItemESP.lua — item ESP.
- modules/visuals/WorldESP.lua — world visuals.
- modules/misc/Freecam.lua — freecam.
- modules/ui/UI.lua — UI, watermark, inventory panel, mobile button, config/menu and unload.
